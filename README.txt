OPEN THE WEBSITE
Double-click index.html. The complete site runs locally and offline.
Keep index.html, style.css, app.js, events.js, and the assets folder together.

WHAT IS INCLUDED
- Responsive competition website with the society's white logo.
- Animated digital core with a motion pause control.
- Team and individual event filters.
- All five competition briefs with full rules and judging criteria.
- Search across the five event rule sets.
- Original competition guidelines PDF and extracted reference text.

CONTENT
Rules come from “XOR '26 Competition Guidelines .pdf” in the parent folder.
Dates, deadlines, and registration/submission links are awaiting announcement.
The society logo comes from Downloads/LOGOS/PNG/csnc white_.png;
only transparent margins and resolution were reduced for website use.
The website is the event information site, not a competition entry.

EDITING
index.html: page content, general rules, navigation.
events.js: competition data and complete competition rules.
style.css: layout, colors, typography, responsive design.
app.js: filters, search, accessible dialogs, and canvas animation.
assets/: local society logo, PDF, and extracted guideline text.

HOSTING
Upload this folder's web files to any static website host.
No build, package installation, API keys, external fonts, or server is required.
This delivery has not been published online.

ACCESSIBILITY
Includes keyboard navigation, modal focus handling, Escape to close,
reduced-motion support, motion pause, labeled search and event controls,
and a skip link. The PDF remains available when JavaScript is disabled.

VERIFICATION
JavaScript syntax and local asset references checked.
Full competition text checked against the source PDF.
